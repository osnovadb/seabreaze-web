# Перевод интерфейса портала GetsEstate на азербайджанский — правила для переводчика

Команда GetsEstate (сейлзы, бэк-офис в Баку, финансы, руководители рынков) работает в нём и во фрейме Bitrix24. Клиенты видят только страницы подборок, согласий и письма.

## Решения ревью к образцу (обязательны)
- «Комиссия» в меню и текстах для партнёров → «Xidmət haqqı»; «komissiya» — только в финансовых таблицах команды.
- «пул» → «endirim büdcəsi». «Подборка», «Подбор» → «Mənzil seçimi».
- Письма: «Здравствуйте, {n}!» → «Hörmətli {n}!»; тексты для WhatsApp — «Salam!».
- «владелец» (роль владельца портала) → НЕ «sahibkar» (это «предприниматель»). Писать «rəhbərlik» («…rəhbərliklə və ya bazar rəhbəri ilə razılaşdırılır»), а роль в списках ролей — «Rəhbərlik (owner)».
- **Никаких падежных и порядковых суффиксов сразу после заполнителя** `{x}`: «{f}-ci mərtəbə» даёт «3-ci» вместо «3-cü»; «{c}-dən» не согласуется с валютой. Переставляйте фразу: «Mərtəbə {f}», «mərt. {f}», «versiya {v}», «{c} valyutasından», «{d} tarixinədək», «{a} məbləğində», «{n} müştəri». Это правило для ВСЕХ строк.
- «Планировка» → «Mənzilin planı»; «Лобби блока» → «Blokun lobbisi»; «Похожие свободные» → «Oxşar satışda olan mənzillər»; «Опции» → «Əlavə opsiyalar» (не «seçimlər», чтобы не путать с «seçim» — подборка); «Запрошено» → «Sorğu göndərilib»; «Переключить» → «Dəyiş»; «Выйти из клиента» → «Müştəri rejimindən çıx».
- «Сейлз», «Продавец» (роль) — «satış meneceri». «Квалификация» клиента — «müştərinin profilinin doldurulması» в текстах, в коротких подписях «Profil» / «Kvalifikasiya» — выберите одно и держите везде («kvalifikasiya» допустимо как термин). «Кандидат» — «namizəd».
- «Рекомендатель» — «tövsiyəçi» (помечено для вычитки носителем, но используйте).
- «Холд 24 ч» — «müvəqqəti saxlama (24 saat)».

## Техника
- Вход: JSON-массив объектов `{key, ru_shown, en}`. `key` — русский ключ (его НЕ менять), `ru_shown` — как строка видна по-русски (иногда отличается от ключа — переводите смысл `ru_shown`), `en` — английский перевод для понимания контекста.
- Выход: один JSON-объект `{ "<key>": "<az>" , ... }` со ВСЕМИ ключами входа, в файл, путь которого указан в задании. Писать через python `json.dump(obj, f, ensure_ascii=False, indent=0)`. Затем проверить: число ключей совпадает, каждый заполнитель `{...}` из ключа присутствует в переводе ровно теми же именами, нет кириллицы в переводе.
- Сохранять HTML, `\n`, «»-кавычки менять на “…”, тире —, знаки %, $, €, ₪, названия брендов (Sea Breeze, BRABUS, Premium Residence, Marina Village, Bitrix24, GetsEstate, Profitbase, KYC, PIN, CRM, Units, Telegram, WhatsApp, Caspian) не переводить. Коды статусов и технические слова латиницей (Inactive, Queued, Requested и т. п.) оставлять как в `en`.
- Если строка — короткая подпись (кнопка, заголовок колонки, пункт меню) — короткая форма интерфейса («Yadda saxla», «Göndər»). В подсказках, уведомлениях, письмах и на страницах клиента — «Siz/Sizin/Sizə» с заглавной и вежливые формы.
- Отказы и ошибки мягко и с выходом («Zəhmət olmasa, … yoxlayın»).
- Буквы ə ı ö ü ğ ş ç İ — настоящие.
- Не обещать доходность, рост цен, ВНЖ.
- Если строка очевидно техническая (только код, URL, формат) — вернуть как в `en`.
