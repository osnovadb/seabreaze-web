## Экраны с номерами на кнопках

К каждой роли — альбомные листы «<язык> · <роль> · экран N»: снимок портала, оранжевые рамки и номера на кнопках, справа расшифровка (у иврита зеркально).

Переснять, когда поменялся интерфейс:
1. Туннель к QA-экземпляру: `ssh -f -N -L 3043:127.0.0.1:3043 root@72.56.89.30`.
2. `cd docs/role-guides/shots && npm i puppeteer-core@23.11.1 && node shoot.mjs ru` (en, de, he) — снимки и координаты кнопок в `out/<язык>/`. Только просмотр страниц, данные не меняются; строки автотестов «QA …» и строки с чужой почтой прячутся, телефоны маскируются.
3. `node preview.mjs ru prev.png <id…>` — проверить, что рамки попали в кнопки.
4. В Figma пересобрать листы и залить картинки через upload_assets (заготовки `img:<язык>:<id>`).

Кадры и подписи к номерам — `shots/plan.json` (кнопка ищется по русской подписи через словарь портала или по CSS-селектору).
