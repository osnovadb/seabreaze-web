# Поэтажные планы Premium Residence из кабинета агента Profitbase

Источник — кабинет агента pb21387.lka.profitbase.ru → проект → корпус → «Floors». Права на материалы Premium Residence есть по договору.

Каждый этаж — отдельная картинка `pb21387.profitbase.ru/document-management/thumbnails/floor_10000_10000/uploads/layout/21387/<hash>.jpg`.
Файлы открываются без входа и без ключа виджета. Ключ виджета (pbApiKey) и токены сессии не используем — решение 30.10.2026.

Как собрать заново:

1. **Адреса.** В Chrome откройте «Floors» корпуса и щёлкайте этажи снизу вверх (так список не сдвигается). Адреса картинок видны в сетевых запросах вкладки. Список `корпус<TAB>этаж<TAB>hash` → `urls.tsv`, картинки → `img/<корпус>-<этаж>.jpg`.
2. **Квартиры из базы.** CSV в `units.csv`: корпус, номер, этаж, площадь, терраса, сад, тип, id.
3. **Разбор.** `python run_all.py`, нужны Pillow, numpy, scipy и tesseract. Что делает `parse.py`:
   - находит красные подписи квартир;
   - читает номер и площадь;
   - определяет границы здания и коридор.

   `build.py` сопоставляет подписи с квартирами этажа: по площади, при повторах — по соседям в ряду. Контуры строит по площади и прижимает к толстым стенам. Картинки для проверки кладёт в `dbg/`.
4. **Экспорт.** `python export.py` обрезает поля, ужимает картинку до 3000 px и пишет `out/*.jpg` и `import.sql`.
5. **Загрузка.** Скопируйте `out/` в FILES_DIR портала (владелец www-data, права 640) и выполните `import.sql` от суперпользователя.

Итог на 04.11.2026: 46 планов (A, B — этажи 2–12; C, D — этажи 1–12), контуры у ~98 % квартир. Неточные места правятся в «Объекты → Разметка → Разметить квартиры».
