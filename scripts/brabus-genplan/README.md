# Генплан BRABUS Island Baku — блоки на аэрорендере

11.11.2026, по просьбе Дениса — «разметить блоки на самой картинке, как у Premium».

- **Картинка** — рендер застройщика `BRABUS_PRESENTATION (1)-5.PNG` из папки «Xarici görünüş _ Exteriors _ Внешний вид» (~/Downloads/Brabus). Кадр — по острову: x 10–94 %, y 20–80 % исходника, уменьшено до 2400 px, JPEG 86.
- **Где какой блок** — по схемам KEY PLAN на листах планировок застройщика (Profitbase Арада):
  - A — прямое крыло, на рендере справа;
  - B — изгиб над аркой входа, посередине;
  - C — диагональное крыло, слева;
  - D — дуплексы 1-го этажа по внешнему периметру подиума. На этом ракурсе их не видно, поэтому они размечены полосой у основания здания;
  - Twin Villas — ряд вилл вдоль пляжа.
- **Контуры** — `polygons.json`: доли ширины и высоты картинки. Ключ `block` = `buildings.name`, у блоков BRABUS нет `external_id`.

Залить на стенд или в бой:
1. Файл скопировать в FILES_DIR портала как `<uuid>.jpg` (www-data, 640).
2. Добавить строку в `portal.files`.
3. В `portal.genplans`: `image = '/files/<uuid>'`, `polygons = polygons.json`, `file_id = <uuid>` (upsert по project_id).

Поправить контуры можно руками в «Объекты → BRABUS → Генплан».
