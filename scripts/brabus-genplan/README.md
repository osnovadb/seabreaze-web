- **Контуры** — `polygons.json`: доли ширины и высоты картинки. Ключ `block` = `buildings.name`, у блоков BRABUS нет `external_id`.

Залить на стенд или в бой:
1. Файл скопировать в FILES_DIR портала как `<uuid>.jpg` (www-data, 640).
2. Добавить строку в `portal.files`.
3. В `portal.genplans`: `image = '/files/<uuid>'`, `polygons = polygons.json`, `file_id = <uuid>` (upsert по project_id).

Основной ракурс правится руками в «Объекты → BRABUS → Генплан»; дополнительный — пока только в базе (`views`).
