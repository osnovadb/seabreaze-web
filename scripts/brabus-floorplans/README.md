# Поэтажные планы BRABUS Island из листов застройщика

Источник — поквартирные листы планировок (Profitbase Арада через сайт партнёра Treva), которые `scripts/treva-import.mjs` кладёт в `directus_files`.
На каждом листе есть панель FLOOR PLAN: весь этаж блока, квартира листа залита серым.

Как собрать заново (нужны Pillow, numpy, scipy, opencv-python-headless):

1. **Листы и квартиры.** CSV `map.csv` (id, name = корпус, floor, number, unit_type, filename_disk) по квартирам источника `treva:brabus`, листы из `UPLOADS_DIR` — в `sheets/`.
2. **Сборка.** `python build.py`:
   - находит панель FLOOR PLAN — нижний правый светло-серый прямоугольник листа;
   - выравнивает листы одного этажа по медиане (phaseCorrelate) — у 3–4-го этажа блока A листы сдвинуты на 30–40 px;
   - чистый план этажа = медиана по листам, так серая заливка уходит;
   - план поворачивается так, чтобы длинная ось здания легла горизонтально (узкий вертикальный план в портале растягивался в «сосиску»), и обрезается по зданию — стрелка и подпись листа в кадр не попадают, север показывает компас портала (`north_deg`);
   - квартира листа = то, чем лист темнее чистого плана этажа (разница > 28). Порог по серому не годится: светло-серые сады, террасы и штриховка есть на всех листах и давали волнистые контуры (12.11.2026);
   - контур прямыми линиями: повёрнутый прямоугольник, если заливка занимает ≥ 85 % его площади и он не заходит на соседей больше чем на 3 %; иначе (угловые квартиры со скруглённым фасадом, Г-образные) — многоугольник по заливке с допуском 0,6 % периметра; привязка к квартире — по стояку (две последние цифры номера, как `riser()` в `lib/catalog.ts`).

   Пишет `out/*.jpg`, `out/plans.json`, картинки для проверки — в `dbg/`.
3. **Экспорт.** `python export.py` → `upload/` и `import.sql`. Файлы `upload/` — в FILES_DIR портала (владелец www-data, права 640), `import.sql` — в базу портала.

Итог на 11.11.2026: 31 план — блок A этажи 3–13, B 5–13, C 3–13, контур у каждой квартиры. На 3-м этаже контуры шире стен: в них входят частные сады и террасы, как на листах застройщика.
Блок D (30 квартир, «1-й этаж») не собран: на его листах 14 разных крыльев, а портал показывает один план на этаж. Виллы — отдельные дома, поэтажного плана нет.
