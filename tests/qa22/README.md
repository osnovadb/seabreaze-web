# QA 2.2

Сквозные тесты портала 2.2 против QA-экземпляра на ams (своя база `seabreeze_qa22`, стенд и бой не трогаются).

```sh
ssh ams 'sh /opt/ge-portal22/src/tests/qa22/run.sh'          # всё: юнит, сквозные, Bitrix24
ssh ams 'sh /opt/ge-portal22/src/tests/qa22/run.sh --no-b24' # без Bitrix24
```

| Набор | Что проверяет |
| --- | --- |
| 01_access | матрица «роль × раздел», вход, изоляция клиентов, рекомендатель, права на действия |
| 02_attach | кандидат 14 дней, квалификация (245), соперники, дубли по 9 цифрам и e-mail, клиент из АЗ, спор, пауза |
| 03_registrations | пакет, ответ, отказ, продление, правило молчания, напоминание, истечение |
| 04_bookings | холд, чужой холд, скидка и согласование, потолок, подтверждение, отказ, лимит и очередь, Release pending, «переговоры о цене» |
| 05_money | доли по ролям, формула партнёра, транши (3 правила), начисления, реестр, акт, согласие, перенос, клаубэк, корректировка |
| 06_kyc | минимум документов, созаёмщик и компания, кто проверяет, Compliance, загрузка клиентом |
| 07_consent_privacy | ссылка согласия, отзыв, отказ, напоминания 3/14 дней, формы с галочками, удаление (без сделки и со сделкой) |
| 08_partner_tools | личная ссылка и фид, ловушка ботов, рекомендатель, заявка агентства, сотрудники агентства, Inactive |
| 09_security | внутренние адреса, робот, обработчик Bitrix24, токены, чужой акт, IDOR, поддельная cookie |
| 10_i18n | экраны партнёра (DE/HE/EN), команды (EN), клиента — русские «хвосты» (мягко, список в out/i18n.txt) |
| 11_b24 | исходящий обмен с Bitrix24: лид, сделка, стадии до Won, Installments/Aftercare, согласия, заявка сайта, удаление |
| 12_race | гонки: бронь, холд, регистрация одного человека, двойной транш, двойной договор |
| 13_misc | версии условий, подборка под брендом партнёра, передача клиента, табу, рынки и словари, выгрузки |
| 14_crawl | обход по ссылкам под каждой ролью — без 500 |
| 15_tick | фоновая обработка без ошибок и без дублей |
