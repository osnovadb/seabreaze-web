# Тесты портала v2

Ведёт QA-сессия в ветке `qa-v2` (worktree `~/Downloads/Claude/ge-portal-qa`), сливается в `v2`.

- `npm test` — юнит-тесты чистых функций (`node:test` + `tsx`), без базы и сети.
- Тесты, помеченные в названии как пограничные случаи, фиксируют ожидаемое поведение: пока баг не исправлен, они падают — это и есть отчёт.

Страницы проверяются на локальном dev-сервере (`npx next dev -p 3042`, база `seabreeze_v2` через туннель на 5433, вход `/dev/login?as=<email>`).

- `PORTAL_URL=http://localhost:3042 npm run test:int` — интеграция: прямые запросы к server actions локального `next dev` + проверка состояния в базе (`DATABASE_URL` из `.env.local`, только `seabreeze_v2`). Тест сам возвращает статусы клиентов, но в истории клиентов, аудите и уведомлениях остаются записи прогона.
- Для тестов документов (М8) нужны файлы активных шаблонов в `./dev-files`: их имена в `portal.doc_templates → files.disk_name`, копировать с ams из `/opt/ge-portal2/files/`. Локально нет LibreOffice — PDF не собирается, тест проверяет docx, права, номера и статусы. Созданные документы тест удаляет, но номера по счётчику расходуются.
